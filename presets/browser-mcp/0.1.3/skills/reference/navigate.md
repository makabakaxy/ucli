# Navigate Commands

## go — Navigate to a URL

```bash
ucli browser navigate go --url https://example.com
ucli browser navigate go --url https://github.com/login
```

## back — Go back to the previous page

```bash
ucli browser navigate back
```

## forward — Go forward to the next page

```bash
ucli browser navigate forward
```

Use `ucli browser navigate <action> --help` for full parameter details.

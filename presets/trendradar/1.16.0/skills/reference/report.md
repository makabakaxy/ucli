# Report Commands

## generate — Generate daily/weekly summary report

```bash
ucli trendradar report generate --report-type daily
ucli trendradar report generate --report-type weekly
ucli trendradar report generate --report-type daily --date-range '{"start":"2025-01-01","end":"2025-01-01"}'
```

Also supports: `--report-type` (daily/weekly), `--date-range`

Use `ucli trendradar report generate --help` for full parameter details.

# Trending Commands

## list — List trending topics by frequency

```bash
ucli trendradar trending list
ucli trendradar trending list --top-n 20 --extract-mode auto_extract
ucli trendradar trending list --mode daily --top-n 10
```

Also supports: `--top-n`, `--mode` (daily/current), `--extract-mode` (keywords/auto_extract)

Use `ucli trendradar trending list --help` for full parameter details.

# Layer operations — layer-set

## set opacity — Set the layer opacity

```bash
ucli ps layer set opacity --opacity 10 --document-id 1
```

## set blend-mode — Set the layer blend mode

```bash
ucli ps layer set blend-mode --blend-mode NORMAL --document-id 1
```

## set visibility — Show or hide the layer

```bash
ucli ps layer set visibility --visible true --document-id 1
```

## set locked — Lock or unlock the layer

```bash
ucli ps layer set locked --locked true --document-id 1
```

Use `ucli ps layer <action> --help` for full parameter details.
